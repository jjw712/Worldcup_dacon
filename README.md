# 잠.물.마

**잠깐 물만 마시지 말고 내 말도 들어다오**

경기를 관찰하고 문제를 메모한 뒤, 하이드레이션 브레이크의 화면상
180초(실제 최대 60초) 안에 가장 중요한 전술부터 전달하는 웹 기반 축구
감독 시뮬레이션입니다.

## 핵심 플레이

1. 대한민국 선수 11명의 기본 위치를 드래그해 조정합니다.
2. 경기 중 2D 전술판, 문자 중계, 코치 피드백과 선수 상태를 관찰합니다.
3. 다음 브레이크에서 전달할 내용을 메모합니다.
4. 하이드레이션 브레이크에서 전술 지시를 확정합니다.
5. 지시 비용은 브레이크 타이머에서 즉시 차감됩니다.
6. 변경된 전술의 효과와 대가를 경기 흐름과 리포트에서 확인합니다.
7. 체력, 카드, 사기와 감독 신뢰를 유지하며 조별리그 3경기를 진행합니다.

## 실행 방법

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

기본 개발 주소는 `http://localhost:3000`입니다.

## Cloudflare 공개 배포

최초 한 번 `npx wrangler login`으로 Cloudflare 계정을 연결한 뒤 실행합니다.

```bash
npm run deploy:cloudflare
```

배포가 끝나면 출력되는 `workers.dev` 주소를 제출 URL로 사용합니다.

## 검증

```bash
npm test
npm run build
```

- 브레이크 타이머 감소 및 즉시 차감
- 지시 비용 범위와 선수 이해도 효과
- 동일 시드 경기 재현
- 관찰 구간과 하이드레이션 전환
- 캠페인 승점 및 경기 간 상태 연결

## 기술 구성

- React 19, TypeScript, vinext
- HTML Canvas 2D 전술판
- 브라우저 localStorage 캠페인 저장
- 규칙 기반 경기·코치 분석 엔진
- 시드 기반 의사 난수
- Vitest 단위 테스트

## 주요 디렉터리

```text
app/                  페이지와 전역 스타일
game/components/      전술판과 각 게임 화면
game/engine/          경기, 지시 비용, 타이머, 캠페인 계산
game/data.ts          팀·선수·3경기 설정 데이터
game/types.ts         핵심 상태와 도메인 타입
public/               공유 이미지 등 정적 자산
```

## 데이터 및 라이선스

팀 구성과 선수 능력치는 시뮬레이션을 위해 작성한 가상 데이터입니다. 실제
선수 사진, 국가 협회 문장, FIFA 또는 대회 공식 로고를 사용하지 않습니다.
경기 결과는 생성형 AI가 아니라 규칙 기반 코드가 계산합니다.
